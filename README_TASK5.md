# Growfinix Task 5 – External API Consumer

## Objective

This project connects to a public weather REST API and displays weather information based on the city entered by the user.

## Technologies

- Python
- Requests
- JSON
- wttr.in Weather API

## Files

- weather_api.py
- input.png
- output.png

## How It Works

1. The user enters a city name.
2. The program sends a GET request to the weather API.
3. The API returns weather data in JSON format.
4. The program extracts the required information.
5. The weather report is displayed in the terminal.

## Run

```bash
python weather_api.py
